6 core workflows
W1 Student onboarding
College email OTP → Profile details + stream → Skill assessment (AI-graded) → Portfolio upload → First service listing → Dashboard
W2 Client onboarding
Email signup → Company details → Razorpay KYC verification → Post first job (guided) → Dashboard
W3 Job posting + bidding
Client posts job (title, brief, budget, deadline) → Matching algorithm notifies relevant students → Students submit proposals (AI pricing hint) → Client reviews bids + student profiles → Client shortlists + messages candidates
W4 Hiring + escrow
Client selects proposal → Razorpay escrow payment initiated → Funds locked on platform → Order created, student notified → Kickoff message + deadline confirmed
W5 Work delivery + AI gate
Student submits files + notes → Platform extracts content → Claude API evaluates vs brief (score 0–100) → Pass (≥70): client notified, AI-reviewed badge applied → Fail (<70): issues shown to student, resubmit required → Max 3 revisions
W6 Completion + payout
Client reviews delivery (72hr window) → Approves: escrow auto-releases to student wallet → Dispute: admin mediation flow → Both leave mandatory reviews → Portfolio item auto-generated → Trust score updated
