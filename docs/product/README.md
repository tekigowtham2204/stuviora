> live elsewhere (`docs/STUVIORA_MASTER_PLAN.md`, `docs/HANDOFF.md`,

> consults before building, hiring, fundraising, or pitching.

## How to use these docs

- **New engineer**: read 00 then 03. Skim 04.
- **New designer**: read 00 then 02 then 04.
- **Investor or partner**: read 00, 01, 05, 06, 09.
- **Founder kick-off**: re-read 01 and 07 every quarter; refresh 06 monthly.
- **Anyone debating a feature**: 04 is the source of truth on what is in
  scope. If a feature is not in 04, it does not get built.

## Style rules

- Premium, considered, specific. No marketing fluff. No em-dashes, no
  en-dashes (HANDOFF.md hard ban).
- Money in INR with tabular alignment.
- Every claim that could be a fact has a number, a source, or both.
- When in doubt, cite the master plan section
  (`docs/STUVIORA_MASTER_PLAN.md` §X).
